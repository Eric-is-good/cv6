# 文明6 网页版 · Opus47

一个纯前端的中文版"文明"类回合策略游戏，无后端、无构建步骤。直接在浏览器打开 `index.html` 即可游玩。

## 特性

- 六边形地图（pointy-top axial 坐标），程序化地形生成（草原/平原/森林/雨林/丘陵/山脉/沙漠/苔原/雪原/海岸/海洋）
- 资源（小麦/牛/鱼/鹿/铁/马/黄金/宝石/石材/葡萄酒）与战略加成
- 12 种单位：开拓者、工人、侦察兵、勇士、弓箭手、长矛兵、骑兵、剑士、投石车、骑士、火枪手 等
- 城市系统：人口、食物、产能、生产队列、建筑、边界扩张、城防
- 完整科技树（18 个科技）+ 市政树（13 个市政），分时代解锁
- 8 个文明（中国 / 罗马 / 埃及 / 希腊 / 波斯 / 蒙古 / 日本 / 印度），可选执政
- AI 文明：自动扩张、生产、研究、宣战、进攻、外交
- 战争迷雾、视野、外交（宣战 / 缔结和平）
- 四种胜利条件：科技 / 文化 / 征服 / 分数
- 通知日志、本地存档（localStorage）

## 玩法

打开 `index.html` 即可开始游戏，默认执政中国。

### 操作
- **左键点击**单位或城市进行选中
- 选中己方单位后，**绿色高亮格**移动，**红色高亮格**攻击
- **拖动**地图平移，**滚轮**缩放
- **结束回合**按钮推进时间（AI 同回合行动）
- 顶部按钮：科技树 / 市政树 / 外交 / 保存 / 读档 / 新游戏 / 帮助

### 胜利条件
- **科技**：研究 `太空飞行`
- **文化**：完成 `全球化` 市政
- **征服**：消灭所有其他文明
- **分数**：达到 1500 分；或第 300 回合按分数判定

## 文件结构

```
index.html        - 主页面
styles.css        - 样式（暗色金棕色调）
favicon.svg       - 图标
src/
  data.js         - 静态数据（地形/资源/单位/建筑/科技/市政）
  rand.js         - 随机数 + 值噪声
  hex.js          - 六边形坐标工具
  map.js          - 地图生成 + 起始点
  game.js         - 游戏状态、回合、AI、序列化
  render.js       - Canvas 渲染
  main.js         - UI 控制器、输入、面板、模态
```

## 浏览器兼容
现代浏览器（支持 ES Modules）。建议 Chrome / Edge / Firefox 最新版。
