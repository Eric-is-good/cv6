# CV6 Web Edition

一个无需构建工具、可以直接在浏览器中游玩的单人回合制 4X 游戏。目标是持续复原《文明 6》的核心游戏循环，而不是只呈现静态界面。

## 当前可玩系统

- 13×9 程序化六边形世界：地形、地貌、河流、资源、领土与战争迷雾
- 三个文明：新汉、罗马和埃及，包含领袖、城市与文明配色
- 单位系统：移动力、寻路、视野、生命值、经验、驻防、休整、近战和远程战斗
- 城市系统：人口增长、住房、地块产出、生产队列、建筑与单位训练
- 科技树和市政树：前置条件、每回合推进与解锁内容
- 建造者地块改良、开拓者建立新城市
- AI 文明探索、发展、生产、宣战、进攻与占领城市
- 外交关系、宣战、议和、统治/科技/分数胜利条件
- 浏览器本地手动存档与自动存档
- 桌面和移动端响应式界面

## 运行

```bash
cd /home/Anon/code/cv6
python -m http.server 8768 --bind 0.0.0.0
```

打开 `http://127.0.0.1:8768/`。

## 操作

- 点击单位，再点击“移动”查看本回合可抵达地块。
- 远程单位可以使用“远程攻击”选择射程内目标。
- 点击城市后选择生产项目；完成项目需要连续推进回合。
- 顶栏可以选择科技、市政、外交和游戏菜单。
- 快捷键：`M` 移动、`F` 驻防、`R` 科技树、`Space` 下一回合。
