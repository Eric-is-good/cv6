# 文明 6 · 网页版（中文）

一款基于 HTML5 Canvas 的回合制 4X 策略游戏，灵感来自《文明 6》。纯前端实现，**无需后端、无需构建**，用浏览器直接打开 `index.html` 即可游玩。所有代码在 `dev_glm52` 分支上独立完成。

## ✨ 特性

- **六边形地图**：基于柏林噪声程序化生成，包含海洋/海岸/草原/平原/沙漠/冻土/雪原/丘陵/山脉等地形，森林/雨林/沼泽/绿洲等地貌，河流、淡水和海岸判定。
- **资源系统**：加成资源（小麦/牛/石料/铜/鱼…）、战略资源（马/铁/硝石，需科技揭示）、奢侈资源（香料/丝绸/宝石）。
- **地块改良**：建造者可修建农场、矿山、牧场、采石场、种植园、渔船（受科技解锁）。
- **城市经营**：开拓者建城，自动工作地块；食物增长人口、产能建造、文化扩张边境、住房限制；可建造纪念碑/粮仓/图书馆/市场/兵营/城墙/工坊/大学/剧场/银行/工厂等十余种建筑，并可金币购买。
- **单位与战斗**：开拓者、建造者、战士、投石兵、侦察兵、弓箭手、矛兵、骑兵、剑士、投石车、长矛兵、桨帆战船…近战/远程/攻城/海军，含地形防御、驻防、城市攻防与占领。
- **科技树**：从古代到工业时代 30+ 项科技，层层解锁单位/建筑/改良与战略资源。
- **对手 AI**：多个 AI 文明会建城、扩张、生产、探索、剿蛮与攻城；蛮族营地会不断派出劫掠者。
- **迷雾战争**：单位/城市提供视野，已探索区域记忆、未可视区域变暗。
- **三种胜利**：科学（研发全部科技）、统治（消灭所有对手文明）、分数（坚持到终局）。
- **全中文界面**：顶部资源/研究栏、单位侧栏与动作栏、城市面板、科技树、事件日志、新手帮助。

## 🎮 操作

| 操作 | 说明 |
| --- | --- |
| 左键单位 | 选中；再点蓝格移动，点红框敌人/城市攻击 |
| 右下动作栏 | 建立城市 / 建造改良 / 驻防 / 解散 / 跳过 |
| 左键城市 | 打开城市面板（生产、金币购买） |
| 拖拽 / 方向键 WASD | 平移地图 |
| 滚轮 | 缩放 |
| `Y` | 切换地块产出显示 |
| `空格` | 结束回合 |
| 顶部「科技树」 | 选择研究项目 |

## 🚀 运行

直接双击 `index.html`，或用任意静态服务器：

```bash
# 任选其一
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

## 🧱 项目结构

```
index.html          入口与界面骨架
styles.css          样式
js/
  util.js           随机数/六边形数学/噪声/辅助
  data.js           地形、地貌、资源、改良、单位、建筑、科技等数据
  map.js            地图生成（地形/地貌/资源/河流/产出）
  units.js          单位移动、寻路、战斗结算
  cities.js         城市建城、产出、增长、生产、扩张、攻防
  tech.js           科技树研究、解锁、胜利判定
  ai.js             迷雾可见性、AI 文明、蛮族
  render.js         Canvas 渲染（地形/迷雾/单位/城市/高亮）
  ui.js             中文 HUD、城市面板、科技面板、通知
  input.js          鼠标/键盘输入
  game.js           游戏主控：初始化、回合循环、胜负
```

## 🔧 技术说明

- 纯原生 JavaScript（经典脚本，非 ES 模块），可直接以 `file://` 打开，无跨域与构建依赖。
- 六边形采用**轴向坐标**（pointy-top）；寻路为带地形消耗的 A*；视野为基于单位/城市视距的范围合并。
- 战斗采用强度差指数伤害模型，含地形/驻防/河流修正与城市反击。

> 本分支（`dev_glm52`）为独立实现，未参考仓库内其他分支的代码。
